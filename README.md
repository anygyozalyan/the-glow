# 🌸 TheGlow

**TheGlow** is a modern, responsive cosmetics website built with **React (Vite)**.  
It’s a complete **e-commerce frontend** featuring all the core functionality an online store needs.

---
## ✨ Key Features

-  Fully **responsive design** for all screen sizes  
-  **Shopping cart** with add/remove item functionality  
-  **Checkout page** for order placement  
-  **Product search** implemented with **Flag.js**  
-  **Sidebar menu** and intuitive navigation  
-  Data stored locally in **JSON** format (inside the `data` folder)  
-  **State management** with **Redux**  
-  **Routing** implemented using **React Router (BrowserRouter)**  
-  **React Context API** used to avoid props drilling  
-  **Unit tests** written with **Vitest**

---

## 🛠️ Technologies Used

- **React (Vite)**
- **Redux**
- **React Router**
- **React Context API**
- **Flag.js**
- **JavaScript (ES6+)**
- **HTML5 / CSS3**
- **Unit Testing (Vitest)**

---

## 🚀 About the Project

**TheGlow** was designed as a clean and modern e-commerce frontend for a cosmetics brand.  
It demonstrates core frontend concepts such as routing, global state management, context usage, and testing.
